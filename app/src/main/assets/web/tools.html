How removal works

Every app installed on the device — system and user — is listed below. Pick whatever you want removed. Removal uses pm uninstall --user 0, which is fully reversible.

Gaming-performance services (joyose, migameservice, gamecenter.sdk.service, enhance.gameservice) are intentionally excluded from recommendations — removing them hurts gaming performance instead of helping it.

Packages marked 🔒 are core system components and are locked here to prevent bricking the device.
